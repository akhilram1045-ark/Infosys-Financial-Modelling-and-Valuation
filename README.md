# Infosys Ltd. – Financial Modeling and Valuation Project

## Project Overview
This project presents a complete financial analysis and valuation of Infosys Ltd. using Microsoft Excel. The model includes historical financial analysis, integrated three-statement forecasting, Discounted Cash Flow (DCF) valuation, Comparable Company Analysis (CCA), and financial ratio analysis.

## Objectives
- Analyze Infosys financial performance.
- Build an integrated 3-statement model.
- Estimate intrinsic value using DCF.
- Compare valuation using market multiples.
- Evaluate profitability and efficiency.

## Project Components

### 1. Company Profile
Overview of Infosys business model, industry position, and revenue segments.

### 2. Historical Financial Analysis
- Income Statement
- Balance Sheet
- Cash Flow Statement

### 3. Ratio Analysis
- Profitability Ratios
- Liquidity Ratios
- Leverage Ratios
- Efficiency Ratios

### 4. Three-Statement Financial Model
Forecasted:
- Revenue
- EBITDA
- EBIT
- Net Income
- Working Capital
- Capital Expenditure
- Cash Flows

### 5. DCF Valuation
- FCFF Method
- WACC Calculation
- Terminal Value
- Enterprise Value
- Equity Value
- Implied Share Price

### 6. Comparable Company Analysis
Valuation based on:
- EV/EBITDA
- P/E
- Other market multiples

### 7. DuPont Analysis
ROE decomposition:
ROE = Net Profit Margin × Asset Turnover × Financial Leverage
